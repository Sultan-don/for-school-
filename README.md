# Orchestra — презентация

Актуальная версия проекта: 23 октября 2026.

## Запуск

Откройте терминал в папке orchestra и выполните:

python3 -m http.server 8000 --directory dist

Затем откройте http://localhost:8000

## Файлы

- dist/index.html — слайды и структура
- dist/style.css — оформление
- dist/script.js — анимации, навигация и переводы RU/UZ/EN
- dist/assets — шрифты, библиотеки, изображения и QR-код

Сборка и установка зависимостей не требуются. Для публикации на статическом хостинге укажите папку dist.

## Вступление для выступления

В начале добавлены четыре главы: представление Султанбека (с интерактивным сертификатом IT Park в блоке IT-координатора), «Аль-Хорезми», «Prezident iqtidorli farzandlari» и первый этап отбора UzCombinator. Затем идут все 13 исходных глав Orchestra. Всего 17 глав. Новые слайды доступны на RU / UZ / EN.

Управление: стрелки или Page Up / Page Down для переходов, Home к началу, End к контактам, Esc для обзора, F для полноэкранного режима. В главе «Продукт» стрелки последовательно показывают пять экранов. Клик по сертификату открывает его в полном размере.

Резервная копия перед добавлением сертификата: `backups/before-cert-20261023/`.
Исходная версия без вступительных глав: `backups/before-intro-20261023-215510/`.

Название второй программы сверено с официальной публикацией: https://www.president.uz/oz/lists/view/8127 . Достижения и цифры новых слайдов приведены со слов выступающего.
